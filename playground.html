    Playground

    Protocol playground

    Build DUST-20 payloads and watch them validate as you type. Everything runs in your browser with exact integer arithmetic — there is no wallet, no private key, no signing and no network request.

    ✓

    Nothing here can spend anything

    These builders produce JSON payloads and arithmetic. They never ask for a key, never construct a transaction and never talk to a server. Your inputs stay in this page — the only thing that leaves is the shareable link you choose to copy.

    Deploy builder

    A deploy fixes a ticker's supply and its satoshi backing rule permanently. max_sats is derived here so you can see the arithmetic, but it is a required field — a deploy that omits it is rejected rather than having it inferred.

    Mint builder

    A mint resolves an accepted deployment and creates units. Three numbers must agree: the deployment's unit size, the sats in the payload, and the real value of the Bitcoin output carrying the inscription.

    Payload inspector

    Paste any DUST-20 content to parse it locally against the strict reader profile. Malformed data is reported, never silently corrected: no missing field is filled in, no value is rounded, and no unknown field is quietly ignored.

    Inspect a payload

    Reports the operation, every field, the derived arithmetic, and each reason it would be rejected.

    Must be a single flat JSON object whose values are all strings. Nesting, numbers, duplicate keys and trailing content are all rejected.
    Needed to check a mint. Without a resolved deployment there is no unit size to validate against.
    Supply the real output value to check a mint's declared backing against Bitcoin.

    DUST

    DUST-20

    DUST-20 binds every token unit to an exact number of satoshis. Deploy and mint are inscriptions; every later movement is an ordinary Bitcoin spend of the satoshis that carry the units.
